Ley de Hooke: F = −k·x
Movimiento: m·x'' = −k·x − c·x'

Energía disipada: Wᵣ = ∫ c·v² dt. Es el trabajo (negativo) hecho por la fuerza de rozamiento. Con c = 0 permanece en 0; con c > 0 crece monótonamente hasta igualar la energía mecánica inicial, que es cuando el bloque se detiene.

Balance energético: E_inicial = E_total + Wᵣ.
